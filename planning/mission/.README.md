# Mission Planning

## Quick Version

This folder is for human-readable mission planning notes.

Use it before a plan becomes a flight-ready mission file.

## Details

Good things to keep here:

- route sketches
- flight-window plans
- operator checklists
- payload/drop-off strategy notes
- Task 1 and Task 2 runbooks

When a plan turns into an actual vehicle mission file, place that file in `actuation/missions`.
