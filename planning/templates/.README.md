# Planning Templates

## Quick Version

This folder is for reusable planning documents.

Use templates to keep checklists, test plans, and mission notes consistent.

## Details

Good template candidates:

- pre-flight checklists
- test-flight logs
- issue reports
- mission runbooks
- post-flight review notes

When creating a new mission document, copy a template and fill it in somewhere more specific, such as `planning/mission`.
