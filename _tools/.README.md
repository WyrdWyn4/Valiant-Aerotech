# Tools

## Quick Version

This folder holds scripts used during setup, calibration, and field checks.

Current useful tool:

```text
servo_calibrate.py
```

Use it to measure Vivi camera-servo PWM values so the code can tell whether the camera is facing down or front.

## Details

### Servo Calibration

Run this while Mission Planner is connected to Vivi and forwarding MAVLink over UDP:

```powershell
python .\_tools\servo_calibrate.py --connect udpin:127.0.0.1:14550
```

The script samples `SERVO_OUTPUT_RAW.servo9_raw` for both camera positions and writes:

```text
integration/pipelines/task_one/configs/servo_calibration.json
```

If Mission Planner is using the radio COM port, do not connect this script directly to the same COM port. Use MAVLink UDP forwarding instead.
