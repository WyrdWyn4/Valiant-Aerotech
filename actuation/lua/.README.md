# ArduPilot Lua Scripts

## Quick Version

This folder holds Lua scripts that run on ArduPilot-supported flight controllers.

These scripts are vehicle-side automation helpers. Review and bench-test them before copying anything to an aircraft.

## Details

Current scripts include:

```text
arm.lua           arming helper
payload.lua       payload/release helper
safety.lua        safety helper
stabilize.lua     stabilize-mode helper
throttle_two.lua  throttle helper
```

Before flight:

1. Confirm the script matches the target vehicle.
2. Confirm the required ArduPilot parameters are set.
3. Test on the bench with props removed.
4. Keep a known-good copy of the previous script.
