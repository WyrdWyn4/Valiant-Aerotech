# Actuation Missions

## Quick Version

This folder is for mission files that are ready to load into vehicle tooling such as Mission Planner.

Only put flight-ready or review-ready mission files here.

## Details

Use this folder for:

- Mission Planner waypoint exports
- vehicle-specific mission plans
- final or near-final flight routes

Keep rough planning notes in `planning/mission` until they are ready to become vehicle mission files.
