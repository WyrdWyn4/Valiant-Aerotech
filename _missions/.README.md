# Missions

## Quick Version

This folder is for shared mission files that do not belong to one specific vehicle package yet.

Keep files here only when they are useful to the whole team or are waiting to be sorted into a more specific folder.

## Details

Use this folder for:

- draft waypoint files
- exported mission plans
- mission notes that need to be shared across subteams

Move vehicle-specific files into `actuation/missions` once they are ready for flight use.
