# Integration Exports

## Quick Version

This folder is for generated outputs from pipelines.

Review anything here before using it as an official competition submission.

## Details

Typical outputs:

- Task 1 target reports
- Task 2 photo exports
- debug JSON files
- processed logs

Official ConOps deliverables should use the required filenames, for example:

```text
Task_1_<team_name>_targets.txt
Task_2_<team_name>_target_<target#>.jpg
```

Generated outputs can become stale quickly. Prefer regenerating them from the latest pipeline when possible.
