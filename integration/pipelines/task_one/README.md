# Task 1 Shared Helpers

## Quick Version

This folder holds shared Task 1 support code that is not part of the main Vivi package.

Current contents:

- `common/servo_map.py`: reads Vivi camera orientation from SERVO9 PWM
- `configs/servo_calibration.json`: saved PWM calibration values

## Details

### Camera Orientation

Vivi's camera servo has two useful positions:

```text
DOWN  = ground-facing camera
FRONT = forward-facing camera
```

`servo_map.py` reads `SERVO_OUTPUT_RAW.servo9_raw` from MAVLink and compares it against the saved threshold.

### Calibration

Calibration is generated by:

```powershell
python .\_tools\servo_calibrate.py --connect udpin:127.0.0.1:14550
```

Re-check this at the venue if the transmitter, receiver, servo endpoints, or flight controller setup changes.

### Current Caution

The calibration file should have a large separation between DOWN and FRONT PWM values. If the separation is small or the standard deviation is high, re-run calibration before relying on automatic camera-mode detection.
