# Integration Configs

## Quick Version

This folder is for configuration files used by scripts and pipelines.

Do not commit secrets, service-account keys, tokens, or private credentials here.

## Details

Use this folder for safe templates and local configuration examples, such as:

- connection defaults
- sample API config files
- non-secret pipeline settings

If a tool needs a real credential file, keep that credential outside the repo and point to it from a local config file that is ignored by Git.
